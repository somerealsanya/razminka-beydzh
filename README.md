# Разминка: бейдж участника

Практическое задание для студентов **2 курса КФУ ИТИС**.

## О проекте

Пятнадцать небольших задач на JavaScript, сгруппированных по темам. Задачи решаются последовательно: первые — только в консоли, с десятой — результат виден прямо на странице.

## Темы

| Задачи | Тема |
|--------|------|
| 1–5    | Переменные и арифметика |
| 6–9    | Функции |
| 10–12  | DOM: находим элемент и меняем его по клику |
| 13–15  | Другие события: input, mouseenter, keydown |

## Структура

```
index.html   — страница с бейджем и элементами управления
style.css    — стили
tasks.js     — файл для решений
```

## Как работать

1. Открыть `index.html` в браузере.
2. Писать код в `tasks.js` — каждая задача обозначена комментарием.
3. Раскомментировать строку с `console.log` для проверки.
4. Сохранить файл и обновить страницу — смотреть результат в консоли и на странице.
